# Bloodbath - RPG Data Management System

A high-performance operational dashboard for managing complex RPG game states, inventory, and player data.

## 🚀 Tech Stack
- **Frontend:** JavaScript / CSS / HTML
- **Backend:** Supabase (PostgreSQL)
- **Deployment:** Vercel

## ⚙️ Key Features
- **Relational Database:** Complex structures for items, stats, and loot tables.
- **Audit Workflow:** Manual approval system for character updates.
- **Automation:** Logic-driven mission reports and calculation engines.

*Note: This is a private project for active game sessions. Source code is for portfolio demonstration purposes.*
